# pfa-week01
Labyrinth Gui

This tool procedurally generates a single-path circular labyrinth in Maya's python script editor. Ring walls with one continuous winding route from an outer
entrance to the center of the labyrinth with NO dead ends.

This script is meant to be run in the python tab of the Maya script editor. When executed you can then use the “Circular Labyrinth Generator” window’s
sliders to set different parameters within the labyrinth; ring count, radius, wall size and click generate. 

With more time I think I would maybe add a color wheel option to the Gui and as well maybe a variety in the shpaes the labyrinth could be; a square, triangle, rectangle, and maybe even walls that swerve in diferent ways.
